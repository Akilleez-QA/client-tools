# Proposed protocol48 tests — not authored or executed

A future reviewed portable gate should compile the actual candidate protocol helper, codec and file-channel. It must preserve the first failure, have strict warnings and ASan/UBSan, and freeze inputs before its first attempt. No SDK, VM, engine allocator or actual callback registration is involved.

1. Golden explicit bytes for install and consumption ACK, exact lengths 136/128, boundary sentinels after output buffers, all field offsets checked without using raw native struct copies as the oracle. Confirm ACK constant0x100e, CallbackAck0x100c, SessionClose0x100d and old API opcodes unchanged.
2. Compare bounded encodeCallInto with vector encodeCall for the same representative inputs, including zero spans and nonzero generic spans. Reject null/short buffers before changing buffer or written. Source audit of fixed writer/ACK path verifies it has no allocation path; any allocation-instrumented portable test must be separately scoped, never substituted with a real engine allocator workload.
3. Install request accepts exactly the nonzero registration and expected ordinary header. Reject zero registration, wrong kind/opcode/session-origin fields, wrong request/lane, nonzero cause/lease, every forbidden Call field, payload/trailing byte, reserved field, and each old version1/2. The authenticated session/replay owner is external and cannot be proved by this test.
4. Install success requires exact retained registration echo. Each allowed refusal has zero echo; reject success with zero/wrong registration, refusal echo, unknown status, wrong envelope, any extra result field, and lengths other than128. Rejection leaves output enum untouched. Ordinary generic replies must keep their callback-zero rule; no global relaxation.
5. Capture FileAckExpected from each actual decoded FileOpen/Close/Seek/Read request with retained registration. Round-trip the fixed ACK for causal and unsolicited requests, including nonzero retained lease where permitted by the independent admitted origin. Ensure expected original opcode remains the file opcode while emitted opcode is the new ACK constant. Invalid/default request cannot establish an expectation.
6. For each ACK independently mutate version/kind/opcode/request/cause/lane/lease/registration/original-file-opcode, every forbidden Call field, length and payload. All must reject. EOS CallbackAck must reject even with otherwise matching fields. A valid ACK should never be fed to the mapper's new-file monotonic intake.
7. Demonstrate stateless duplicate validation is not consumption authority: a later composition test must pass a validated ACK to real mapper.acknowledgeConsumed once, and reject duplicate/early/wrong-session use while preserving required ownership. Do not add a fake local-intake field or claim protocol-only test covers that mapper state.
8. Stream59 success: valid null and BorrowedSample aliases require exact parent echo. Reject missing/wrong parent kind/slot/generation, invalid alias resource kind, payload/callback/extra values, wrong envelope or version. Keep target alias output unchanged on failure. This is a success-only contract check, not a stream backend test.
9. All codec entry points (Call, Result, Eos; bounded/vector encoding and decoding as applicable) reject old v1/v2 headers after the v3 bump. No mixed-version fallback. Rejections must not manufacture Installed or a normal file callback result.

Registration replacement, actual SDK return, transport ownership, ACK send/receive ordering, buffer lifetime in Endpoint, one-time mapper settlement, thread TLS and vendor shutdown remain subsequent composition obligations; this candidate enables none of them.
