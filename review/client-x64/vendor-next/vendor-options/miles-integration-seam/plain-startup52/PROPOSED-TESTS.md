# Prospective deterministic tests for52 — not authored or run

A later reviewed portable gate should compile the actual plain_startup.cpp and private/failure_boundary.cpp, using only a narrowly declared portability treatment for the public Windows callback syntax and a **scripted statically linked definition** of the nine private native calls. It must never compile a copied SDK body or load a vendor library. Keep native/private declaration checks separate. Freeze all authored test inputs and preserve the first attempt before any run. No runner or executable is supplied now.

1. **Pre-startup text and independent snapshots.** Bind a plain recording reporter, call set_redist_directory and last_error before startup, and have the private supplier expose mutable char arrays. Assert the returned pointer is not the supplier buffer, copy its contents, mutate the supplier buffer, and verify the adapter snapshot is unchanged. Call the other getter/setter and verify the first pointer/text is unchanged. For same-function replacement, verify the new text; never read a pointer after its specified invalidation boundary. Include null and nonnull empty native results as distinct cases. Assert no reporter invocation on these native values.
2. **Input retention before the setter.** Pass a mutable short stack buffer. Inside the scripted setter assert the supplied pointer is distinct from that buffer and already contains the complete text. Retain the supplied pointer privately, mutate the caller buffer after return, make further setter calls that force list growth, and verify each previously supplied input still has its original bytes before shutdown. At scripted shutdown entry, read each pointer to prove it has not been released early; do not dereference it after actual adapter shutdown returns. Test a setter input that aliases a still-valid previous adapter result; copying must precede replacement. This examines adapter storage, not vendor retention behavior.
3. **Exact native values and arguments.** Script startup zero and nonzero, driver null/nonnull, pointer-width signed preference values above32 bits, and non-stereo/full-width driver arguments. Assert exact input capture and returned values, no narrowing or injected policy, no implicit shutdown after zero startup, and no failure reporter. Script speaker output through the private call seam; the portable check does not validate the real SDK's speaker output implementation.
4. **Version is a caller-buffer operation.** Pass guarded caller storage and a positive count. The supplier records exact pointer/count and writes (a) valid text, (b) a genuine empty result and (c) only a deliberate prefix without a NUL. Assert the wrapper performs no fill, extra termination, throw/fault or status substitution; compare only the raw bytes, never form a C string for case(c). Never claim these scripted cases reproduce every Windows resource-query result. Separately source-review that the native TU calls the actual AIL_MSS_version macro.
5. **Normal shutdown ownership ordering.** Script pre-startup text followed by startup and shutdown; supplier verifies all retained input strings at shutdown entry. Assert exactly one delegated shutdown per public call, and that a later legitimate new startup/text lifecycle creates fresh snapshots. Any allocation tracking must concern only this portable private text layer, not the engine allocator or a SDK lifetime claim.
6. **Failure containment requires isolated child processes.** Run each terminal case in a fresh child with a durable event stream to the parent. Cases: reporter missing; duplicate/null bind; null directory; null/zero/negative version extent; supplier throws a std::exception or non-standard object in each of the nine operations; reporter returns; reporter itself throws. The parent requires reporter event ordering where bound, no post-call/result event, and abnormal termination from the fallback. Do not replace the nonreturning production path with a recoverable test-only throw. A returning reporter must not let the public call return; a throwing reporter must not escape to an outer engine-shaped catch. Since this tests std::abort, root must separately approve that narrowly isolated process test. No termination execution is authorized by this document.
Allocation-failure instrumentation is excluded from the authorized first gate. Negative cases use scripted private C++ exceptions only; no allocator fault workload is authored or run.

The failure cases must use source-backed event oracles rather than accepting any crash as success. With a bound reporter, require the expected reason class and exactly one reporter invocation before fallback termination; distinguish an assertion failure, sanitizer finding or unrelated crash. For the no-reporter case, verify normal harness setup first and require the expected abort termination after the public call starts. A later strict runner must preserve raw compiler/run logs and child outcomes, with named scenarios rather than a check-count quality claim.

A portable scripted supplier establishes snapshot, argument, and catch-path behavior only. Engine STLport compatibility needs a separate actual engine-header compilation of the plain public boundary; native SDK signatures/macros need a separate selected native TU gate. Neither is authorized here, and no portable fake proves actual Miles values, callbacks, quiescence or engine failure handling.
