# Callback correlation and forward-return join

Continue the selected native-shaped private bridge design. This is the control-thread component needed to connect the two independently owned pipes, using real SessionFileOwner37 and Coordinator34. It does not start a thread, install SDK callbacks, or replace the SDK with scripted services in production. The endpoint owner must authenticate the peer before supplying a session identity; this object does not implement authentication.

Prediction: a validated forward return that races ahead of a causal file-reply consumption ACK leaves the admitted command pinned. Processing that ACK settles it without blocking the control thread. The reverse request number is looked up in a retained record; the peer never supplies the client-local intake ordinal. An unsolicited request stays unsolicited even while a game command is active. Neither a stale session, replay, wrong lane/lease/cause nor an early/duplicate ACK reaches another file invocation.

Implementation: one control thread mutates mapper, coordinator and file owner. Preallocate a bounded reverse-to-intake table. Publish a command's wire-to-local-admission association before command send. Retain that association through observed return plus causal ACK settlement. The separate command thread may only post observations to this owner and wait on its own result; it must never call these methods concurrently. Forward result bytes remain the outer transport owner's responsibility. No blanket synchronization or nested SDK dispatch is introduced.

Portable validation will compile the real mapper, coordinator, owner, codec and file adapter, with the previously explicit scripted job/worker from37. Scenarios cover both return/ACK orders, exact reverse mapping, background callbacks during command and idle, causal lane/lease/cause validation, replay, early/duplicate ACK, malformed frames, failed executor, slot capacity and next-command ordering. It cannot establish Endpoint cross-thread ownership, Windows worker events, actual callback execution, SDK shutdown/quiescence or gameplay fidelity. ASan/UBSan and strict compiler warnings apply. One initial build/run after source review; preserve any failure and repair in a named successor, not in-place retry. Production checkout untouched. No engine or allocator-fault workload.

Pretest independent review identified that an undifferentiated observed return cannot authorize lock/unlock lease transitions after a known vendor refusal. Before freezing the first test, this mapper slice is restricted to Ordinary actions. Lock/unlock reject before admission. Their later composition must distinguish actual vendor return from refusal without inventing a lease. The original review remains preserved; no test had run.
