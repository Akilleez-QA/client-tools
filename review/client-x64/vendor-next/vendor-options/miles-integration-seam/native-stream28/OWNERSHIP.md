# Stream28 source contract

This is a partial source facade. Each function delegates once to the corresponding actual native SDK function. It does not validate stale handles, change the vendor result, select a new backend or implement pipe transport. The existing driver belongs to one selected implementation through teardown; mixing handles from native and pipe implementations is outside the contract.

After a nonnull open, the caller owns one stream and closes it exactly once before its driver/session is torn down. Null stays null. `OwnedStream*` is an opaque identity with ordinary pointer aliases, not a unique owner that C++ enforces. The direct implementation privately round-trips the actual SDK stream pointer, as the existing native driver facade does. It allocates no second proxy after the vendor open. Use after close, double close and concurrent lifecycle changes are not checked by this slice. There is no destructor that silently calls Miles.

The filename is the existing NUL-terminated input pointer. The adapter passes it unchanged, including any native special syntax; it does not normalize paths or infer an image extent. The usage excerpt conservatively requires that the caller retain its filename, driver, file-service configuration and selected session through close. That precondition does not assert that the SDK retains or copies the filename. File callback thread/executor ownership remains separate unresolved integration work.

`streamMem`, loop count, loop offsets, status and millisecond values all retain the actual signed32 SDK types. No signed sentinel is narrowed to unsigned, no status is reduced to a bool or new enum, and loop offsets receive no scaling or reinterpretation as milliseconds or sample indices. Offset origin/alignment and special `streamMem` values remain vendor policy. The explicit ms functions use milliseconds. The public output pointers remain nullable and forward directly; compile checks cover `(out, null)`, `(null, out)` and `(null, null)` shapes, not the vendor runtime acceptance or writes for those combinations. Null filename or stream arguments likewise are not newly guaranteed valid by a pointer declaration.

The usage excerpt retains eight distinct calls. It is never executed here. Normal return from a successful open reaches close; failed open leaves `opened=false` and all numerical observation fields unobserved. A future throwing pipe implementation needs its own uncertain-completion cleanup policy; this example does not claim exception-safe close or retry. It is not Audio's streaming policy: actual Audio also sets borrowed-sample rate/volume/reverb and can register EOS callbacks. An immediate start/query/close sequence is only a source-shape exercise, not useful playback, a timing oracle or faithful lifecycle proof.

`AIL_stream_sample_handle` yields a sample associated with the stream. Actual Audio uses it for sample rate/volume/reverb calls. This slice deliberately declares no corresponding facade getter or borrowed controls. Future work must select a distinct borrowed type tied to its owning stream and invalidate its aliases when that stream closes; it must never be accepted by allocated `OwnedSample` release. No cast/conversion helper bypasses that missing contract here. The portable contract checks the distinct existing driver, allocated sample and owned stream types without importing any SDK or protocol type into the public API.

The source packet contains authored code and text only. Callback/EOS registration, borrowed-sample lifetime and controls, shared unknown-buffer extent calls, pipe mapping, native linking/vendor execution and whole-client replacement remain outside this gate.
