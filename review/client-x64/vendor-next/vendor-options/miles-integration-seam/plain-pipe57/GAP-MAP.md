Parent source provenance and the authored diff are recorded separately.

The existing37 core has more private operations than the eight exports, but those are not accidentally exported as `ClientMiles` functions. Do not link the old public37 object alongside this one. ## Remaining public surface

Only eight definitions are exported here. Preferences, speaker spec, listener/control/playback functions have private37 implementations but need guarded exports against the final selected composition. Existing pipe policies include get1/get42, set42=16/64, and driver22050/16/stereo/zero flags; the plain types do not remove those restrictions or establish native64 parity.

Text functions remain deliberately unexported.37's `last_errorOwned:233` requires running state, unlike52's pre-startup native access. `set_redist_directoryOwned:239` returns private owned text; it is not the public returned-pointer contract.52's separate snapshots could be reused after the backend call shape and private retention are reconciled, but a pointer into a temporary OwnedText is never acceptable.37 `MSS_versionOwned:251` uses SessionVersion's bounded owned-string policy.52 forwards actual macro writes, including genuine empty/partial writes. Copying a remote success string or inventing an empty failure result would silently change that contract; the caller-buffer operation needs a separately reviewed private wire/host result design.

No file callback installation is exported.53 can prepare the selected file table but the outer installer still owns installation reply validation and installed-state publication. No EOS registration, lock/unlock, input image binding/WAV transfer, missing telemetry, or remaining API is fabricated. The actual Audio path cannot use this partial surface end to end: it requires redist/file registration and playback/EOS, among others. Native54 object evidence and parent55 review do not establish these missing source connections.
