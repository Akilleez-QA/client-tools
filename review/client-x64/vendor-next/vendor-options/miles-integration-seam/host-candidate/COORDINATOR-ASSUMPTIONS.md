# Session candidate against the proposed ownership boundary

Review only. Existing candidate stays frozen; no new lifecycle operations or product assembly are approved by this note.

The x64 process should retain game policy and object identity; the x86 process should own the original Miles runtime, its actual audio device and Bink's use of that device. The isolated SessionLifecycle is useful implementation material, but its private registry and boolean quiescence argument are not the final coordination architecture.

1. **One process-global session authority.** Miles preferences, startup/shutdown, error strings, callbacks and redistribution modules are global state. A central coordinator must enforce the single session assumption currently documented by the candidate, bind every command to its session and prevent another SessionLifecycle instance or direct vendor path from bypassing it. Its control-thread identity must remain stable from startup to shutdown. Static function binding does not provide this authority.

2. **One resource graph, not several registries.** The candidate tracks Driver→OwnedSample only. The final graph also needs streams, borrowed samples, Bink/device consumers and all retained buffers. Bink cannot receive a marshaled substitute HDIGDRIVER; it must use the actual same-process driver. Driver closure requires all of those children and in-flight users to have ended. The candidate's const registry accessor and two-phase samples-then-drivers cleanup do not establish that broader lifetime. A central registry should be injected or coordinated once, not independently populated by each component.

3. **Quiescence must be a state transition, not a caller guess.** A `true` argument currently means an external coordinator has proved callbacks and dispatch users cannot reference the resource. Final assembly needs one admission/closing/draining/retired state machine: stop new admissions, account for outstanding causal calls and callback acknowledgments, establish original-vendor callback termination, then invoke destruction and retire identities/buffers. A registry closing flag rejects lookups but cannot cancel or finish already-running vendor work. Neither successful sample rebinding nor a failed binding is evidence old/new memory is unused.

4. **Causal reverse I/O differs from unsolicited callbacks.** A synchronous AIL_open_stream may need TreeFile responses while its forward call is incomplete. Those causally matched responses must proceed without opening the entire vendor lane to unrelated requests. AIL_lock's logical owner/recursion must survive nested requests; one recursive mutex on one host thread cannot distinguish client lanes. EOS forwarding into game policy has a different exclusion/timing question and cannot inherit reverse-I/O permission. No generic reentrant dispatch queue is justified by the candidate.

5. **Thread and FPU state are fidelity inputs.** The session pins ordinary calls to its constructing control thread. Actual callbacks may originate elsewhere. Coordinator policy must follow measured original behavior, including whether AIL_LOCK_PROTECTION is enabled and which original caller thread is excluded, rather than forwarding callbacks wherever convenient. Capture relevant x87/MXCSR/provider state before selecting a host policy; argument-bit identity alone is insufficient.

6. **Private immutable copies have deliberately conservative lifetimes.** RetainedBuffers provides staging/commit/retire mechanics. Central ownership must associate every token with its session/resource/call and provide meaningful bounded backpressure before calling the vendor. Caps are not proof of original capacity equivalence. Vendor error strings need synchronous copy before unrelated calls overwrite global state, then a defined client shadow lifetime. The separate store must never become another implicit source of resource truth.

Smallest coherent assembly is a session coordinator driving genuine initialization, one actual driver and one owned sample with explicit resource/buffer ownership, while retaining the original game's policy on x64. It is still gated on runtime lifecycle verification and the parent's actual-engine callback/TreeFile fixture. Compile/preflight success does not settle audio equivalence, callback latency, exclusion or Bink behavior.
