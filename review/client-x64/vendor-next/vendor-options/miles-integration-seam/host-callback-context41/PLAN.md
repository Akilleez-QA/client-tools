# Call-thread callback origin scope

Source plus one frozen portable strict C++11 ASan/UBSan std::thread gate only. No VM/native SDK/engine or actual vendor callback execution; no operational host adoption. Public Miles APIs unchanged.

A host call thread may enter one immutable stack Scope around future actual Backend execution. Origin carries trusted host session incarnation, wire request, lane, lock lease and local admission ordinal. Session/request/lane/admission must be nonzero; lease0 is valid for an unlocked request. Origin is supplied by validated host admission, never decoded from callback claims. Nested entry is unsupported; foreign-session entry reports a distinct refusal and leaves existing context intact. Invalid entry never installs TLS. Scope is noncopyable/nonmovable and must be constructed/destroyed on the same thread, outlive callbacks on that thread, and outlive no asynchronous work.

TLS contains only a POD pointer to the active immutable stack scope: __declspec(thread) on MSVC, thread_local elsewhere. Snapshot requires the callback session owner's trusted incarnation. Empty TLS means unsolicited callback (including separate vendor worker), not failure/EOF. Foreign session returns explicit mismatch. Snapshot changes output only on Ready, allocates nothing and is throw(). No callback sequence, registration authority, lifetime pin or request admission is minted here. No global active request is consulted; owner assigns fresh callback sequence independently. Exceptions never cross vendor callback boundaries through this helper.

Portable named scenarios: two simultaneous call threads see their own distinct origins; independent background thread remains empty while both are active; mismatched session and invalid snapshot leave output unchanged; nested same-session and foreign-session entries explicitly refuse without disturbing outer origin; invalid origins never install; lease0 succeeds; scope exception unwind clears TLS. One gate invocation, stop/preserve first failure without automatic repair/rerun. Test does not exercise actual vendor threading or prove callback quiescence.
