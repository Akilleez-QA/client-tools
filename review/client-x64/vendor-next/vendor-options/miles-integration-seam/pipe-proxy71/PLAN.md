Three private functions convert trusted existing row addresses explicitly to the public opaque object-pointer token types. They never accept a public token or cast it back. Owned-sample, borrowed-sample and stream lookups scan the existing authoritative lists, compare against sampleToken/streamToken generated from each real row, then use the matched row pointer. Public return values come from those same conversion functions after existing validated publication; genuine null remains null.

There is no second registry, integer token allocation, tombstone table, vendor-object spoof, pointer-to-function conversion or conversion of an untrusted token back into a readable private object. The tokens designate private storage only in the selected pipe implementation. They must never be passed to an actual native SDK call, and callers cannot switch implementations while retaining them.
