# Borrowed stream alias: prospective oracle

2026-09-30, before tests. Preserve 412-check baseline in ../transport-baseline-412-v3. Add insertion tied to one live Stream handle (kind,slot,generation). Repeated same pointer/parent returns identical alias even at capacity; changed pointer for same parent rejects without retarget. Generic borrowed insertion is forbidden. Direct alias close/retire forbidden; only parent retirement invalidates and advances alias generations. Parent closing immediately rejects lookup. Parent retirement then reuse cannot revive old IDs. Two streams may have distinct aliases for the same pointer: ownership identity is parent, not pointer. This does not prove vendor allows shared pointers.

Expected controls: null pointer, wrong-kind/stale/closing parent, forged parent generation, bypass insertion, independent alias retirement all reject. Capacity and low generation ceiling preserve permanent exhaustion. Mutation removing parent-live validation must fail closing-parent test; mutation omitting child retirement must fail slot reuse/exhaustion. No vendor calls or freeing resources. Callback quiescence and session admission remain external. No independent destruction means registry lifetime only, not an SDK release operation.
