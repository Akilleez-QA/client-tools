# Candidate transport: prospective oracle

Scope: schema v1 explicit little-endian frame codec and dispatch-thread-owned resource registry. No vendor calls, process transport, callback admission, locks, or game integration. Protocol owner confirmed controls use Call/Result and EOS uses Event.

Twenty considered options: (1) native struct dump rejected for padding/ABI; (2) explicit LE cursor selected; (3) protobuf rejected pending protocol redesign; (4) XDR rejected endian/schema mismatch; (5) JSON rejected binary float fidelity/size; (6) shared memory deferred lifetime design; (7) direct pointer IDs rejected; (8) monotonic-only IDs considered but bounded reuse selected; (9) generation reuse selected; (10) wrapping generation rejected; (11) permanent exhaustion selected; (12) slot capacity bound selected; (13) registry vendor ownership deferred; (14) session admission deferred distinct component; (15) API text policy deferred adapter; (16) independent golden bytes selected; (17) truncation corpus selected; (18) mutation discrimination selected; (19) cross-ABI native tests selected; (20) sanitizers selected as supplementary host evidence.

Research: RFC4506 (https://www.rfc-editor.org/rfc/rfc4506.html) distinguishes external representation and bounds; our schema is LE, not XDR. CERT INT30-C (https://cmu-sei.github.io/secure-coding-standards/sei-cert-c-coding-standard/rules/integers-int/int30-c/) supports checked arithmetic before operations. Windows process-handle docs (https://learn.microsoft.com/en-us/windows/win32/procthread/process-handles-and-identifiers) do not justify transmitting process-local pointers. Read 2026-09-30. Disconfirmation: modulo counters do not imply safe generation wrap, and round trips alone cannot establish a correct external format.

Prediction: independent literal frame matches encoder; all truncated prefixes fail without publishing output; unknown types, metadata spans, reversed/overlapping/gapped spans, trailing bytes, oversize lengths fail. Exact accepted frames decode same field values on both native ABIs. Resource kind mismatch, null local pointer, closing/stale ID fail; reuse changes generation; exhausted slots never revive. Removing generation increment must make the test executable fail. Fixed low generation ceiling permits bounded exhaustion tests without billions of transitions.

Non-goals: canonical span order does not prove message ordering; global session uniqueness, lane/lease admission, borrowed aliases, parent lifetimes and callback barriers remain external. Caller must quiesce resource before retire. Registry never frees resources. Encoder replaces supplied span metadata using passed payloads; decoder views reference caller-owned immutable bytes.
