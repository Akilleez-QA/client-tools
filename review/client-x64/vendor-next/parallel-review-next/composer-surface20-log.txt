## Client behaviors that punish “fake success” (bridge must match)

| Risk | Source behavior |
|------|------------------|
| `AIL_open_digital_driver` non-null but dead | `getMilesDigitalDriver()` passed to Bink; silent movies or crash inside `binkw32` |
| `AIL_set_named_sample_file` / `AIL_set_sample_file` false | `startSample` aborts; sound id logic continues with warnings |
| `AIL_open_stream` NULL | No stream sample id; large 2d assets fail |
| `AIL_sample_status` / stream status wrong | `getSamplePlayBackStatus` mis-reports `PS_playing` vs `PS_done` |
| EOS/stream callbacks never fire | Looping / `endOfSample` game logic stalls |
| File callbacks success without bytes | `AIL_read` path; corrupt decode |
| `serve()` never runs | Acceptable at idle; breaks once samples play |
| `remove()` without real driver close | Client already skips `AIL_close_digital_driver`; bridge should still tolerate `AIL_shutdown` after leaked handles |

`Audio::install` failure returns `false` and calls `remove()` — **not** fake success at install boundary.

## Likely gap vs a **39-arm `host_dispatch`** (inference only)

A 39-entry dispatch usually covers **boot + digital driver + file hooks + a few sample/stream calls**. This client’s **live** path also needs at minimum:

- Full **file callback** contract (incl. seek modes).
- **Listener** trio on the driver handle (`SoundObject3d`).
- **Sample lifecycle:** allocate, set file (2d named + 3d raw), start/stop/end/release, status, volume levels, loop/EOS.
- **Stream lifecycle:** open (uses path), start, close, ms position, stream callback, `AIL_stream_sample_handle`.
- **3d sample:** position, distances, occlusion, obstruction.
- **Housekeeping:** `AIL_serve`, timer/CPU/latency, `AIL_lock`/`unlock`, `AIL_get_preference`/`set_preference`, room type, `AIL_file_type`/`AIL_WAV_info`, `AIL_last_error`.

Anything only in `mss.h` but not in the table above is **not client-reachable** until something in `Audio.cpp` / Bink calls it.

## Prioritized implementation sequence (real client startup, not full fidelity)

1. **`AIL_startup` / `AIL_shutdown` + `AIL_set_redist_directory`** — match install/remove ordering with client’s `remove()` quirk.
2. **`AIL_set_file_callbacks` + seek/read semantics** — required before any `AIL_open_stream` or sample load from memory cache.
3. **`AIL_get_preference(DIG_MIXER_CHANNELS)` + `AIL_open_digital_driver(22050,16,…)` + `AIL_last_error`** — hard gate for `s_installed` and `getMilesDigitalDriver()`.
4. **Stable non-null `HDIGDRIVER`** — listener APIs on same pointer; document handle lifetime through `AIL_shutdown`.
5. **`BinkOpenMiles` / `BinkSetSoundSystem` compatibility** — validate with `VideoList::install` path (vendor DLL + your driver), not only direct `AIL_*` tests.
6. **`AIL_allocate_sample_handle` + `AIL_set_named_sample_file` + `AIL_start_sample` + `AIL_sample_status`** — first UI/menu `.snd` playback.
7. **`AIL_serve` + `AIL_get_timer_highest_delay` + digital latency/CPU** — `Audio::alter` without watchdog spam.
8. **`AIL_open_stream` + stream start/close/ms position + stream sample handle** — music/large 2d.
9. **3d path:** `AIL_set_sample_file`, 3D position/distances, occlusion/obstruction, EOS callback.
10. **Room/reverb, loop blocks, playback rate, buffered sound APIs** — polish after in-world boot.
