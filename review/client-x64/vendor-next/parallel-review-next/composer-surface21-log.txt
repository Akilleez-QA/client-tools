## Coverage snapshot

| Layer | API map opcodes | Implemented in supplied TUs | Notes |
|--------|-----------------|----------------------------|--------|
| `host_dispatch.cpp` | 61 | **38** (`supports()` == `dispatchImpl` cases) | Vendor calls compile only on **x86 + MSVC 1800**; **no** `Resolver`, transport, or session in this file |
| `metadata_host.cpp` | 61 | **5** (10, 33, 12, 34, 53) | Separate `MilesStartup::dispatch`; needs `validate()` + frame bytes for redist |
| **Union** | 61 | **43** | **18 opcodes** have no case in either file |

**Compile-only vs runtime:** Cases in `host_dispatch.cpp` are real `::AIL_*` forwards, but every path rejects non-zero `bytes`, `text`, `resource`, or `callback` (`InvalidFields`). So wire-shaped calls that match API-MAP for buffers, filenames, or callbacks never reach vendor code through this dispatcher. Runtime also depends on a live `Resolver` (declared in `host_dispatch.h`, not implemented here) and on routing startup opcodes to `metadata_host.cpp`.

**Game callers** (`Audio.cpp`, `SoundObject3d.cpp`): both paths were readable. `SoundObject3d.cpp` only calls listener 3D setters (covered by host). `Audio.cpp` uses many APIs listed below as missing or split across metadata.

## Implemented opcodes (host) vs API map — substantiated semantics issues

| Issue | Where | Defect |
|--------|--------|--------|
| **Wire field gate** | `dispatchImpl` preamble | Any API row needing `resource` Buffer, `text` path, or `callback` token returns **`InvalidFields`** before `switch`; buffer/file/callback families cannot work through this TU as written |
| **`AIL_sample_reverb_levels` (23)** | host case | `resolve` mask is **OwnedSample only**; API row 23 says target **Sample**; game uses **borrowed** `AIL_stream_sample_handle` for **set** reverb on streams (host **set** allows Borrowed; **get** does not) |
| **`AIL_set_sample_3D_*` / obstruction / occlusion** | host cases | **OwnedSample** only; consistent with current game (owned HSAMPLE for 3D), but stricter than API “Sample” wording for rows 36–38, 43–44 |
| **`AIL_speaker_configuration` (53)** | metadata case | Ignores `output_mask`; always calls vendor with `(0,0,0,&spec)` and only fills `value[3]` — matches reviewed `Audio::install` call, not full mask contract in API-MAP |
| **`AIL_get_timer_highest_delay` (11)** | host | Returns raw `AIL_get_timer_highest_delay()` in `return_bits` (no `bits()`); API says **U32** — likely fine if type width matches |
| **`AIL_sample_status` (24)** | host | Assigns vendor return directly to `return_bits` (no `bits()`); API **U32** — same note as above |
| **Dual entrypoints** | host vs metadata | Opcodes **10, 12, 33, 34, 53** are **not** in `host_dispatch::supports()`; client/transport must route them to `MilesStartup::dispatch` or they surface as **Unsupported** on host |
| **Lifecycle** | `host_dispatch.h` comment | Explicit: **no** lifecycle/admission/worker policy in host; game **`AIL_lock`/`unlock`** around batch starts still need wire opcodes **13/61** elsewhere |

## Game-critical path vs current handlers (runtime)

| Phase | Representative `AIL_*` in `Audio.cpp` | Covered? |
|--------|----------------------------------------|----------|
| Boot | `startup`, `set_redist_directory`, `set_file_callbacks`, `get_preference`, `open_digital_driver`, `last_error`, `speaker_configuration`, `set_3D_rolloff_factor` | **Partial** (metadata + host rolloff only) |
| Per-frame | `get_timer_highest_delay`, `digital_*`, `serve`, listener 3D (`SoundObject3d`) | **Host** (except lock/unlock) |
| Start sound | `allocate_sample_handle`, `open_stream`, `set_named_sample_file` / `set_sample_file`, callbacks, `start_*`, `stream_sample_handle` for stream volume | **Mostly missing** except `start_*` and many setters **after** handles exist |
| Stop / teardown | `stop_sample`, `end_sample`, `close_stream`, `release_sample_handle`, `shutdown` | **Partial** (`stop`/`end` yes; **close_stream**, **release**, **shutdown** no) |

Without the **factory**, **buffer bind**, **callback**, **lock**, and **stream borrow** families, a wire client cannot reproduce `Audio::install()` → `startSample()` → `alter()`/`serve()` even though **38** “steady state” opcodes are implemented in `host_dispatch.cpp`.
