## 3. Thirty-nine-arm: defects vs `API-MAP.md` (not “unsupported by design”)

### 3.1 Protocol vs host: `BorrowedSample` on getters (real map defect; product does not hit it today)

**Observation:** `API-MAP.md:22,24` document `AIL_sample_position` / `AIL_sample_status` for “owned **or** borrowed”. Host allows only `OwnedSample` (`host_dispatch.cpp:115–127`).

**Disconfirming (for SWG today):** `Audio.cpp` never queries status/position on `AIL_stream_sample_handle`; streams use `AIL_stream_status` (`2716`) and stream ms APIs.

**Discriminating test:** After real `open_stream` + `stream_sample_handle` (opcode 59), issue opcode **24** with `BorrowedSample` target while stream is playing; compare in-process `AIL_sample_status(borrowed)` vs wire host (expect `InvalidResource` on host, API map claims valid Sample target).

### 3.2 Stream volume/rate/reverb: 39-arm ops depend on missing opcode 59 (end-to-end gap, not a bug inside an arm)

**Observation:** Product never stores borrowed handles; it composes inline:

```3211:3212:/home/akilleez/Work/swg-source/client-build-next/src/engine/client/library/clientAudio/src/win32/Audio.cpp
		AIL_set_sample_volume_levels((AIL_stream_sample_handle(sampleStream.m_stream)), leftLevel, rightLevel);
		AIL_set_sample_reverb_levels((AIL_stream_sample_handle(sampleStream.m_stream)), 1.0f, 0.0f);
```

Host implements opcodes **47–48**, **45**, **25**, **21** with `BorrowedSample` (`host_dispatch.cpp:244–253`, `132–134`, `160–162`) but **`AIL_stream_sample_handle` is unsupported** (`supports()` has no case).

**Discriminating test:** Wire-only path: `open_stream` → `start_stream` → host `stream_sample_handle` → `set_sample_volume_levels` on alias; without 59, stream music volume path cannot be exercised (native baseline: hear stream fade with `setSampleVolume` on a stream sound).

### 3.3 `RegistryResolver` does not add semantics beyond registry

**Observation:** `registry_resolver.h:10–16` only checks `allowed` bitmask + `registry.resolve`. Parent-live rules for borrowed handles live in `resource_registry.h:111–115` (transport), not in resolver.

**Hypothesis (unproven here):** Stale borrowed ID after parent close is rejected by registry — **supported by** `preflight.cpp:43–46` (compile-only markers).

**Not a 39-arm opcode bug.**

### 3.4 No defect found in 39-arm for Audio’s **owned** paths

For 2D/3D owned samples, kind masks in `host_dispatch.cpp` match `Audio.cpp` (e.g. `AIL_sample_ms_position` owned-only at `146–148` matches `4251`, `4303`; stream uses opcode **58** at `150–155`).

**Disconfirming:** Preflight explicitly rejects `AIL_start_sample` on `BorrowedSample` (`preflight.cpp:38–39`) — matches product (only owned starts).

## 6. Actionable gaps with one test each (real gaps only)

1. **EOS fidelity** — Start looping 2D SFX with EOS callback; assert `Sound2d::endOfSample` fires without polling. **Fails** without opcodes 16–17 + callback delivery contract.

2. **Lock + start batch** — Stress: queue 10 sounds, one `alter()`; under native, all start inside lock. **Wire:** interleave `AIL_serve` / volume sets between start opcodes without lock **13/61**; compare for dropouts/crashes (hypothesis: race; needs runtime).

3. **Stream open + TreeFile** — Open music stream from `.eap`/tree path (`605`). **Fails** without 15+28 and reverse callback servicing.

4. **Stream volume** — `setSampleVolume` on active stream (`3199–3212`). **Fails** wire path without **59** then 47/48.

5. **Bink intro movie audio** — Play Bink with audio (`ClientMain.cpp:314`). **Fails** if Miles is host-only in another process (driver pointer semantics).

6. **API map vs host on borrowed getters** — Opcode 24 + `BorrowedSample` (**§3.1**); fix map or host for protocol consistency.

---

## 7. What this review did **not** find

- No evidence in `Audio.cpp` that **39-arm** mis-implements **owned** 2D/3D/stream control paths relative to current call patterns (kinds, masks, driver target).
- No use of `AIL_sample_reverb_levels` GET on stream borrowed handles (so host’s Owned-only GET at `164–169` is sufficient for today’s product).
- Filter/capture `AIL_*` at `5439+` is not production-enabled at `Audio.cpp:45–47`.

---

**Bottom line:** The 39-arm host is a compile-only control-plane slice. For SWG audio fidelity, the blocking work is the **22 unsupported opcodes** plus **Bink in-process driver sharing**, not fixing individual arms—except **API-MAP vs host** on borrowed `sample_status`/`sample_position`, and the **hard dependency** of stream UX on **`AIL_stream_sample_handle` (59)** while only its downstream mutators live in the 39-arm set.
