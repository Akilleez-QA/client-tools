## Smallest **no-playback** vertical slice (load + duration + volume + rate)

**Game source chain (no `AIL_start_sample`):**

1. **Cache / duration probe:** `AudioNamespace::cacheSample` → static **`getSampleTime(char const *path, byte *fileImage, int fileSize, …)`** (`Audio.cpp` ~4427–4462):  
   `AIL_allocate_sample_handle` → `AIL_set_named_sample_file` → `AIL_sample_ms_position` → `AIL_end_sample` → `AIL_release_sample_handle`.
2. **Optional metadata:** **`Audio::getSampleInformation`** (~3710): `AIL_WAV_info` + same **`getSampleTime`** for `m_time`.
3. **Volume / rate on a loaded handle (play prep, still no start):** from **`Audio::playSample` 2D path** (~2836+): after `set_named_sample_file`, **`Audio::setSamplePlayBackRate`** / volume via **`Audio::setSampleVolume`** → `AIL_set_sample_playback_rate`, `AIL_set_sample_volume_levels`, `AIL_set_sample_reverb_levels`; readbacks **`Audio::getSampleVolume`**, **`Audio::getSamplePlayBackRate`**.

**Sound2d** uses duration via **`Audio::getSampleTime(SampleId, …)`** only when a **playing** sample exists; the **no-playback** duration you care about for cache sizing is the static **`getSampleTime(path, image, size)`** path above.

## Callback / lifecycle / binding summary

- **Callbacks:** opcodes **16–17** unimplemented; coordinator does not retire registrations (`post_fence_callback_violation` unimplemented). Irrelevant for no-playback probe.

## Concrete narrowing / signature assumptions

| Issue | Where |
|-------|--------|
| **`SessionLifecycle::startup`**: `started = (result != 0)` vs **`AIL_INIT_SUCCESS == 0`** in `Mss.h` | `session_lifecycle.cpp` ~31 — treats success as failure if return is 0 |
| **`AIL_get_preference` / `AIL_set_preference`**: client **`SINTa` 64-bit** vs host **32-bit** checked scalar | `API-MAP` / `CONTRACT.md`; `Audio.cpp` ~1297 casts to `int` |

| **`sound-info-codec`**: `retainedSize > UINT32_MAX` rejected; conservative **null data ⇒ zero length** | Not proven against all vendor outputs until real `WAV_info` on host |
| **`AIL_set_sample_file`**: SDK has **no size**; 3D path passes **`0` block** with cache size only at adapter (`CONTRACT.md`) — distinct from **`set_named_sample_file`** slice |

## Remaining work (ordered, minimal — not a generic RPC framework)

1. **Single registry + coordinator hookup** — lifecycle creates driver/sample; dispatch **`Resolver`** reads same table.
2. **Buffer seal path** — client upload + host `RetainedBuffers`; **remove or narrow** the global “no `resource`/`text`” rejection for opcodes **32** (and **1**, **9**).
3. **Host arms**: **`AIL_startup`**, **`AIL_open_digital_driver`**, **`AIL_allocate_sample_handle`**, **`AIL_set_named_sample_file`**, **`AIL_end_sample`**, **`AIL_release_sample_handle`** (+ fix **startup** boolean).
4. **One synchronous request/reply** (no full 61-op framework) exercising **`cacheSample`/`getSampleTime` equivalence**.
5. **Then** attach existing scalar arms for **volume/rate/ms** on that handle.
6. Optional: **`WAV_info`** + **`sound-info-codec`** on the same sealed image for **`getSampleInformation`**.

**Do not count as done:** 39 compile-only dispatch arms, codec unit tests, coordinator mechanism tests without vendor, or session preflight with DLL unloaded.
