Mutation modes oversize(three bytes for capacity2), nonterminated, missing prefix, historical text-form reply, nonzero callback and wrong request context must leave the entire caller allocation unchanged. Each must reject before the scripted settlement checkpoint, mark actual Session uncertain, call substituted fail once, and refuse subsequent sends. Oversize stays within the wire budget, so it specifically needs request-dependent owner validation. This is evidence for the simulated ordering only, not real LiveChannel scheduling. Prefix-copy correctness is checked after actual Core calls, not merely by decoding a packet.
