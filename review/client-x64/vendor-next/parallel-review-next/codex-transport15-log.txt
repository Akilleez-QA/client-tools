### Display scaling caveat

The Samsung monitor runs a Hyprland logical scale of 2. `grim` region output is two bitmap pixels per logical coordinate. Convert a point in a cropped screenshot back to the desktop with:

`desktop_x = window_logical_x + screenshot_pixel_x / 2`

`desktop_y = window_logical_y + screenshot_pixel_y / 2`

Pointer acceleration makes large relative `ydotool` moves imprecise. Move in smaller increments and verify each result with `hyprctl cursorpos` before clicking.

### Safe UI workflow

1. Identify and focus the exact window by Hyprland address.
2. Capture the window with `grim` and inspect it.
3. Convert screenshot coordinates using the scale rule above.
4. Move the pointer incrementally and verify with `hyprctl cursorpos`.
5. Click or type.
6. Capture again and verify the resulting UI state.
