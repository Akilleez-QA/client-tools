For v120 x64, with `U32` as `unsigned int`, `S32` as `signed int`, `C8` as `char`, empty `FAR`, and `AILCALL` as `__stdcall`, each facade binds the native scalars and forwards the native pointer unchanged.

- **Byte count.** `set_named_sample_file` takes `uint32_t fileBytes` and passes it as the `U32 file_size` argument (`native_sample27.cpp` 49–53). `static_assert` at line 9 requires `uint32_t` and `U32` to be the same type, so the 32-bit width is exact.
- **Signed block and result.** The same function returns `int32_t` and takes `int32_t block`, matching `S32` result and `S32 block` (`Mss.h` 4492–4496). Line 10 requires `int32_t` and `S32` to be the same type. The return is the native `S32` with no conversion (`native_sample27.cpp` 52–53).
- **Suffix and image.** `const char *` and `const void *` match `C8 const FAR *` and `void const FAR *` once `C8` is `char` and `FAR` is empty (`ClientMilesSample.h` 14–15, `Mss.h` 4493–4494). Both pointers are passed through (`native_sample27.cpp` 52–53). Line 11 requires `char` and `C8` to be the same type.
- **Millisecond outputs.** `sample_ms_position` takes `int32_t *totalMilliseconds` then `int32_t *currentMilliseconds` (`ClientMilesSample.h` 16–17) and passes them in that order (`native_sample27.cpp` 59–60). That matches `S32 FAR *total_milliseconds` then `S32 FAR *current_milliseconds` (`Mss.h` 4752–4754). They stay writable object pointers, so null remains representable.
- **Opaque handles.** `allocate_sample_handle` casts `DigitalDriver *` (`HDIGDRIVER`) to `::HDIGDRIVER`, calls `AIL_allocate_sample_handle`, and casts the `::HSAMPLE` back (`native_sample27.cpp` 45–46; `Mss.h` 4418–4419). `set_named_sample_file`, `sample_ms_position`, `end_sample`, and `release_sample_handle` each cast that facade `HSAMPLE` back to `::HSAMPLE` before the matching native call (`native_sample27.cpp` 52, 59, 65, 70). On this ABI those are same-width object pointers, so the casts round-trip the native bit pattern, including null from allocate.
