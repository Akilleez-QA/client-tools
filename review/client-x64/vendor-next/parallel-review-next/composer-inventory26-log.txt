## Prioritized next native-shaped batch (smallest useful)

**Batch 27 — “cached sample on open driver”** (unblocks non-stream Sound2d/Sound3d for in-cache assets; defers streams, EOS/stream callbacks, filters, WAV probe, diagnostics).

Add Miles-shaped wrappers (signatures to be verified against headers), mirroring existing `HDIGDRIVER` + `driverCall` pattern and new opaque `HSAMPLE` session ownership:

| Op | Primary Audio.cpp lines | Prerequisites |
|----|-------------------------|---------------|
| `allocate_sample_handle` | 630, 660 | `s_installed`; valid `HDIGDRIVER` (`s_digitalDevice2d`); increment `s_allocated2d/3dSampleHandles` on success |
| `release_sample_handle` | 3394, 3403 | After `stop_sample`/`end_sample`; null `m_sample`; erase map entry |
| `set_named_sample_file` | 2836 | `HSAMPLE`; **caller-owned** `sampleRawData` + `fileSize` from `s_sampleCache` until stop/release; extension from cache entry |
| `set_sample_file` | 2925 | Same byte lifetime for 3D |
| `start_sample` / `stop_sample` / `end_sample` | 2883+, 3356–3362 | Bound sample; map `m_status` vs `AIL_sample_status` 2706–2711 |
| `sample_status` | 2706, 2711 | Map lookup: 2d vs 3d only (not stream) |
| `set_sample_volume_levels` / `sample_volume_levels` | 3287+, 3173+ | Valid `HSAMPLE`; streams later via `stream_sample_handle` |
| `set_sample_playback_rate` / `sample_playback_rate` | 3244+, 3326+ | Same |
| `set_sample_obstruction` / `set_sample_occlusion` | 3129, 3144 | Sound2d `alter` 454–455 |

**State / ownership (from excerpts):**

- **Driver:** single open digital device used for both 2D and 3D allocate 630/660; pipe must accept same driver identity as startup open.
- **Identity:** game `SampleId` → `Sample2d`/`Sample3d` maps hold `m_sample`; not valid after `releaseSampleId` 3378–3408.
- **Bytes:** `AIL_set_named_sample_file` / `AIL_set_sample_file` reference cache `m_sampleRawData`; must outlive bind through playback until `stopSample`/`releaseSampleId` (no extra copy implied in excerpt).
- **Lifecycle order:** `stopSample` → `AIL_stop_sample` + `AIL_end_sample` (2d/3d) → `release_sample_handle` on release path 3384–3394.
- **Discrimination checks:** `isSample2d` / `isSample3d` / `isSampleStream` before status/stop/release; stream branch must **not** use this batch’s release_sample path 3364–3368.

**Optional same batch (tiny add-on):** `sample_ms_position` + `set_sample_ms_position` 4391, 4251+ for Sound2d time APIs 1224–1243 and temp probe in `getSampleTime` 4437–4455 (second ephemeral allocate/bind/release pattern).
