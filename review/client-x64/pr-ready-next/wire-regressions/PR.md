# Cover galaxy-list and ordinary-container wire encodings

Add the previously undelivered LoginClusterStatus and AutoArray/AutoList regression checks above [archive PR13](https://github.com/Akilleez-QA/client-tools/pull/13), which already includes [wire PR23](https://github.com/SWG-Source/client-tools/pull/23). The two original test commit units change **five files, +256/−35**, with no production or workflow changes. The second commit retains only the test/runner/README portion of the container-count change; its source correction is already in the base. All final harness files match their original bytes.

Nine galaxy-list checks compare two distinct 14-field records, empty/two-record lists and an exact iterator boundary against literal legacy Win32 bytes. Signed boundaries, high unsigned values, unequal addresses and opposing flags make width/order errors observable. Twelve container checks cover 0/1/3 initialized byte elements, seeded output prefixes, literal unsigned-32-bit counts and complete decoding. Expected bytes are not generated by candidate roundtrips.

Run with Python 3, clang++, MinGW-w64 and Wine from the checkout:

```sh
python3 tools/test-wire-compatibility/run.py --bits 32 --require-current-coverage --artifacts artifacts/wire-32
python3 tools/test-wire-compatibility/run.py --bits 64 --require-current-coverage --artifacts artifacts/wire-64
```
