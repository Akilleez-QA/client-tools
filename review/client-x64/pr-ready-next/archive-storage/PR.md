Archive reads currently use allocated capacity as their bound, and several decoders copy a declared payload before checking how many bytes remain. ByteStream growth can also release shared storage before copying from it. This change bounds reads by logical size, checks append arithmetic, and constructs replacement storage before publishing it, including valid self-append and shared-buffer reserve.

String, ByteStream and Unicode decoders preflight payload length before raw access or destination mutation. Unicode decoding copies bytes into aligned string storage. String writers reuse the checked count; AutoArray/AutoList check their unsigned 32-bit counts; Unicode writers check that the payload byte count fits before multiplying or publishing the header. Representable legacy encodings and public field widths/layout stay unchanged. Bound empty/end iterators now consistently accept zero-byte reads; reads through an unbound iterator remain invalid.
