# Separate the int-length memory-move helper from the CRT overload

The shared helper overloads `memmove` with an int length and delegates using unsigned int. On x64 that creates an ambiguous call against the CRT's size_t signature; pointer-difference callers can also become ambiguous. Rename the helper to `imemmove`, delegate with size_t and update its five int-count calls in TCPQueue, Iff and Md5. CRT size_t/ptrdiff_t calls retain the standard name. The production patch is four files, +7/-7 lines.

Adds a compact native regression tool that includes the real foundation headers. Candidate Win32/x64 Release and original Win32 Release each pass 30 valid-buffer checks covering both overlap directions, disjoint and identical regions, zero length, full-buffer bytes and return-pointer identity. Candidate Debug compiles on both ABIs; original x64 is rejected with the expected C2668 overload ambiguity before any runtime execution. The baseline control accepts exactly the two expected ambiguity diagnostics and rejects all additional or unrecognized errors. Fourteen text-only tests cover the classifier, including expected errors mixed with unrelated failures. No fake DebugFatal function, hidden header guard, invalid pointer or negative-length test is used.

The exact three changed caller translation units also compile in all four configurations with candidate library headers first, using existing external project metadata and remaining development dependencies. This is not a complete build of the isolated branch; x64 compiler warnings remain. Commands, source/header identities and limitations are recorded in the evidence packet, and the checkout README documents the standalone header test.

The helper retains its Debug pointer assertions and does not add length-range validation. Removing the global int overload can change Debug-only assertion routing for external ptrdiff_t calls on Win32; the runtime evidence covers valid buffers, not unchanged invalid-input behavior. No full client link or initialized-engine Debug runtime claim is made.
