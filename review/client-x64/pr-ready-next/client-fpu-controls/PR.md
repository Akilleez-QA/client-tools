Windows x64 cannot compile the x87 assembly in `FloatingPointUnit`, and SSE has no selectable intermediate precision. Add an x64 implementation that reads and writes MXCSR control bits, reports precision as fixed by each float/double operation, and makes `setPrecision` unavailable on x64. Restrict CollisionWorld's existing precision save/set/restore bracket to x86 so its caller contract agrees with that API.

Rounding and exception-mask updates preserve sticky exception flags and the saved DAZ/FTZ policy. Saved control words remain architecture-specific. The Win32 implementation, including the precision setter's existing old-state behavior, is deliberately retained; correcting that behavior would require separately reassessing the DPVS PC64 numerical reference.
