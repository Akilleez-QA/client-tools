Windows socket handles and IOCP completion keys are pointer-sized. This patch uses `uintptr_t` for the Windows socket declarations/storage and `ULONG_PTR` for the completion-key outputs in TcpClient and TcpServer. Operation status and transferred-byte counts retain their existing widths. A separate networking-header commit selects Winsock 2 before foundation can introduce conflicting Winsock 1.1 declarations.

The production delta is six files, +18/−6. Four test/workflow files add 334 lines. The shared handle/key repairs mirror the [client network draft](https://github.com/Akilleez-QA/client-tools/pull/2); the include-order prerequisite is specific to the server's existing header structure.
